# 🤖 ALPHA JARVIS MINI

An **Offline AI Cyber Assistant** built in Python with a terminal-based interface.  
Jarvis Mini is designed to simulate a futuristic AI system with system tools, network utilities, and automation features.

---

## ⚡ FEATURES

- 🧠 AI Assistant System (Expandable)
- 🌐 Network Tools (Scan, Ping, IP tools)
- 🔐 Password Generator
- 💻 System Information Monitor
- 📊 Live System Status (CPU, RAM, Disk)
- 🎨 Cyber Terminal UI (Rich + Colorama)
- ⚙️ Modular Architecture (Easy to Extend)

## 🚀 INSTALLATION

### 1️⃣ Clone Repository
```bash
git clone https://github.com/Pak-group-of-Hackers/Jarvis-Mini.git
cd Jarvis-Mini
2️⃣ Install Dependencies
pip install -r requirements.txt

If requirements file not present:

pip install rich colorama psutil
3️⃣ Run Project
python main.py
🧠 HOW IT WORKS
CLI-based interactive menu system
Uses Python modules for system operations
Displays real-time system stats
Executes network and security tools
Expandable AI structure for future upgrades
